THE LAYERS

由外到內，七個向度。

不是把資訊平鋪成百科，而是從「別人先看見的你」一路走到「你其實怎麼運作」。

人物向度

01
語

OUTER LAYER

語言與溝通

日文業務、會議口譯、商務郵件。你對「意思有沒有翻到」不滿足，還會追問語氣、責任邊界、暗示程度與日本客戶實際會怎麼讀。

  • JLPT N1、BJT J2、J.TEST 699。
  • 特別在意正式文件的自然度、禮貌與措辭精準度。
  • 會議紀錄偏好抓主張、條件、承諾、保留事項，而非逐字抄錄。
  • 常見語感題：中で／中旬、見解／検討、責任範圍與模糊表達。
02

PROFESSIONAL EVOLUTION

從工業電腦，到 LCD / TAM

你不是把工作理解成「賣東西」，而是越來越往技術溝通、專案協調、需求翻譯、風險管理靠攏。

Industrial PC→PM / QA / FAE→LCD / T-CON→TAM thinking
  • 熟悉 EOL、RMA、BOM、GPU、PSU、ECC、SSD 等工業電腦議題。
  • 現職延伸到 Open Cell、LCM、T-CON、PMIC、LED Driver、AG/AF/AR、PSE 等。
  • 偏好 Program / Project / Coordinator / BA / Operations 型工作，不喜歡只剩純銷售 KPI。
  • 你最常做的其實是：把客戶語言、供應商語言、工程語言翻成彼此能動的下一步。

COGNITIVE STYLE

精準＋追根究柢

你常從一個名詞出發，最後一路追到原理層。不是愛炫技，而是如果底層模型沒接起來，你會覺得答案像懸空。

  • 強烈在意概念邊界、用詞差異、因果是否真的成立。
  • 會質疑權威，也會質疑自己的第一反應。
  • 容易「窮盡式研究」：非晶矽 → TFT → 光罩；菊花鍊 → AD Board → 系統架構。
  • 你自己也很清楚這是優點兼時間黑洞。
04

KNOWLEDGE SYSTEM

把世界整理成系統

清單、Notion、Obsidian、專案頁、錯誤彙整、學習筆記。你不是單純「愛做筆記」，而是靠外部結構減少腦內雜訊。

NotionObsidianLoopChecklist
  • 偏好可檢核、可分類、可回看，而不是只有漂亮頁面。
  • 習慣把工作中的技術與語言知識做成可重用模板。
  • 常在「數位工具很方便」與「選項太多反而耗腦」之間拉扯。
05

AI → BUILDING

從問 AI，到開始叫 AI 幫你做東西

從比較模型、研究 benchmark，到 Python、VS Code、GitHub Pages、Vibe Coding，再到互動行程網站與 3D 空間。你正在從「使用者」慢慢長成「可以定義系統的人」。

查詢 / 翻譯部署 / 建構
  • 先從 Colab / Python 基礎開始，接著碰 VS Code 與 GitHub。
  • 已成功部署過 GitHub Pages，也開始理解 clone / commit / push。
  • 會比較 Luna、Sol、Astra 的能力與限制，不只看品牌名稱。
  • 你對 AI 的興趣逐漸從「會回答什麼」轉向「能被串成什麼工作流」。
06

VISUAL TASTE

低飽和，不要七彩。

你偏好現代、乾淨、帶一點 editorial 感的版面；大留白、圓形與卡片拼貼、灰褐／軍綠／海軍藍／米色，比滿版資訊牆更像你。

  • 不喜歡過度一致到像套版，也不喜歡所有元素都擠滿。
  • 喜歡便條貼、圓形、模組卡片混搭，但仍要有視覺秩序。
  • 你會直接指出「壓迫感太重」「留白不夠」「模板一致性太高」。

  • 閱讀題材從小說延伸到腦科學、學習方法與心理學。
  • 喜歡 K-pop 舞蹈，也在意「享受課程」勝過同儕競爭。
  • 旅行規劃會細到交通、住宿、動線與備案，但又想保留自由度。
  • 日常問題跨度極大：網站部署可以下一秒接發芽馬鈴薯。

THE THREAD THAT CONNECTS IT

你真正穩定的核心，可能不是某個 MBTI。

而是：想把模糊的東西弄清楚，把零散的資訊接成結構，再把結構變成可以使用的東西。

這條線從心理學、日文、專案管理，一直延伸到 LCD、AI、程式與設計。主題一直換，處理世界的方法其實滿一致。
